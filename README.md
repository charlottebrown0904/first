# 미국 1등주 투자 판단 홈페이지

미국 시가총액 1위 종목에 투자하되, 나스닥·VIX 충격이 오면 금/국채 펀드로 피했다가
돌아오는 규칙을 **46년치 실제 시세로 검증**하고, 오늘 무엇을 해야 하는지 알려주는
로컬 웹 대시보드입니다.

> **투자 조언이 아닙니다.** 과거 시세로 규칙을 시뮬레이션한 결과만 보여줍니다.
> 과거 성과는 미래를 보장하지 않습니다.

---

## 실행

```bash
pip install -r requirements.txt
```

```bash
python app.py --refresh
```

`--refresh` 는 온라인에서 시세를 새로 받습니다(최초 1회 필수, 이후 12시간마다 자동 갱신).
브라우저에서 <http://127.0.0.1:5000> 을 엽니다.

최적 매매법 탐색은 시간이 걸리므로 따로 돌립니다:

```bash
python scripts/optimize_run.py 12000
```

## 매매 규칙

포트폴리오는 매일 **"자산 중 몇 %를 1등주에 둘 것인가"** 하나로 표현됩니다.

```
목표 = 0.0                  ← 충격 후 회피 중
     = 1 - 일부매도비율      ← 1등주 자체가 급락 중
     = 1.0                  ← 평상시
```

매수/매도 이벤트가 아니라 목표 비중으로 쓰면 "일부 매도한 뒤 언제 다시 사느냐"가
저절로 풀립니다. 급락 신호가 풀리면 목표가 1.0으로 돌아가고 포지션이 복구됩니다.

**신호는 전부 어제까지의 종가로 계산하고, 체결은 오늘 종가에 일어납니다.**
`_shift_signals()` 한 곳에서 강제하므로 미래 정보가 샐 수 없습니다.

| 파라미터 | 뜻 |
|---|---|
| `crash_lookback` / `crash_threshold` | 나스닥이 N일 동안 X% 넘게 빠지면 충격 |
| `vix_threshold` | VIX 가 이 값을 넘어도 충격 (0 = 사용 안 함) |
| `shelter_days` | 최소 회피 기간 (거래일) |
| `reentry_calm_days` | 추가 충격 없이 이만큼 지나야 복귀 |
| `trim_lookback` / `trim_threshold` | 1등주가 N일 동안 X% 빠지면 일부 매도 |
| `trim_fraction` | 그중 몇 %를 회피자산으로 옮길지 |
| `gold_weight` | 회피자산 중 금 비중 (나머지는 국채) |
| `initial_krw` / `monthly_krw` | 시작 1천만원 / 매월 50만원 적립 |
| `cost_bps` | 편도 거래비용 (기본 10bp = 0.1%) |

## 데이터

전부 Yahoo Finance(yfinance)에서 받아 `data/cache/` 에 CSV 로 기록하고,
`manifest.json` 에 수신 시각을 남깁니다. 모든 시세는 `auto_adjust=True` 로 받은
**총수익(배당 재투자) 계열**입니다 — 국채 펀드는 수익의 대부분이 이자라서 이게 중요합니다.

| 지표 | 티커 | 보유 기간 |
|---|---|---|
| 나스닥 종합지수 | `^IXIC` | 1971-02 ~ |
| VIX | `^VIX` | 1990-01 ~ |
| 금 펀드 | `CEF` | 1986-04 ~ |
| 국채 펀드 | `FGOVX` | 1980-01 ~ |
| 1등주 | `XOM` `IBM` `GE` `MSFT` `AAPL` `NVDA` | 1962-01 ~ |

백테스트 구간은 네 계열이 모두 존재하는 **1980-01-02 부터 (46.6년)** 입니다.

### 데이터에 대해 알아야 할 것

이 부분은 숨기지 않고 화면에도 그대로 띄웁니다.

- **금 펀드는 1986년부터입니다.** 1980년대 초를 커버하는 금 펀드 두 개
  (`USERX`, `INIVX`)를 먼저 시도했다가 둘 다 배제했습니다.
  `USERX` 는 주가 $53 인 펀드에 $49·$41·$39 짜리 배당이 기록돼 있어(실제 NAV 하락은
  $5~7) 조정계열이 연 31% 라는 말이 안 되는 수익률을 냅니다. `INIVX` 는 1986년
  이후로는 멀쩡하지만, **금 현물이 59% 폭락한 1980-86년 구간에 +9.1%/년**으로
  찍혀 있어 그 구간을 쓸 수 없습니다.
  대신 실물 금을 보유하는 `CEF` 를 씁니다(최대 분배금이 NAV 의 0.3%, 금 현물과
  상관 0.74 / 베타 1.10). **1986년 이전 회피자산은 100% 국채로 처리됩니다.**
- **VIX 는 1990년부터가 진짜입니다.** 그 이전은 나스닥 21일 실현변동성 × 1.15 로
  만든 대용치이고, 화면에 `대용치` 라고 표시됩니다.
- **시총 1위 이력은 큐레이션 표입니다** (`data/seed/leaders.json`).
  과거 시총 순위를 주는 무료 API 가 없어서, 공개된 기업 역사 기록을 월 단위
  해상도로 정리했습니다. 교체일 전후 몇 달은 실제로 1·2위가 엎치락뒤치락하던
  구간이라 날짜에 오차가 있을 수 있습니다.
  **현재 1위만은 매 갱신 때 yfinance 시가총액으로 실시간 확인**하며,
  큐레이션 표의 마지막 항목과 다르면 자동으로 이어붙입니다.
- **환율은 반영하지 않았습니다.** 원화 금액(1천만원, 월 50만원)이 미국 자산에
  그대로 투입된다고 가정합니다. `KRW=X` 는 2003년부터만 있어서 46년 백테스트에
  넣을 수 없었습니다. 실제로는 원/달러 등락이 결과를 크게 바꿉니다.
- 세금과 배당 원천징수는 반영하지 않았습니다. 거래비용만 편도 10bp 로 넣었습니다.

## 과최적화를 막는 장치

파라미터 조합이 345,600개입니다. 46년 데이터로 그걸 다 뒤지면 반드시
"과거에만 잘 맞는" 규칙이 나옵니다. 그래서:

1. **워크포워드** — 학습구간(~2005-12-31)에서만 규칙을 찾고,
   탐색이 한 번도 보지 않은 검증구간(2006-01-01~)에서 다시 채점합니다.
2. **일관성 순위** — 두 구간 점수 중 **나쁜 쪽**으로 정렬합니다.
   한쪽 시대에만 통하는 규칙이 위로 올라오지 못하게 합니다.
3. **안정성 점수** — 각 후보의 파라미터를 격자 한 칸씩 움직인 이웃들의 중앙값 점수.
   이웃이 무너지면 그 규칙은 전략이 아니라 표본의 우연입니다.
4. **퇴화 해 배제** — 회피 비중 60% 초과 또는 CAGR 6% 미만인 후보는 버립니다.
   이 장치가 없으면 탐색이 "90% 국채에 숨어 있기"를 최적해로 고릅니다
   (실제로 초기 실행에서 그렇게 나왔습니다 — 낙폭이 거의 없으니 점수는 높은데
   수익이 국채 펀드와 똑같습니다).
5. **단일 승자 대신 파레토 프론티어** — 수익과 낙폭은 맞바꾸는 관계라
   "최고의 매매법" 하나는 존재하지 않습니다. 프론티어 전체와 그 위의 세 지점
   (최고 수익률 / 균형 / 최소 손실)을 같이 보여줍니다.

## 탐색이 내놓은 결론

12,000개를 무작위로 뽑고 주변을 정밀 탐색해 약 14,000개 규칙을 평가한 결과입니다.
**학습구간(1980~2005)에서만 규칙을 고르고, 2006년 이후는 채점에만 썼습니다.**

### 1. 가설 하나가 깨졌습니다 — "미국 1등 주식은 항상 오른다"

틀렸습니다. **IBM 은 1987년부터 1993년까지 3분의 2를 잃었습니다.**
그동안 나스닥은 오르고 있었기 때문에, 나스닥을 보는 회피 규칙은 아무 도움이 되지
않았습니다. 기본값으로 쓰던 "10일 -12%" 같은 짧은 규칙도 몇 년에 걸친 침몰을
보지 못합니다. 이 구간에서 그런 규칙은 **-73%** 를 맞았습니다.

### 2. 그래서 탐색이 만장일치로 고른 것

상위 15개 규칙이 **예외 없이 전부** 같은 값을 골랐습니다:

| 파라미터 | 선택 | 뜻 |
|---|---|---|
| `trim_lookback` | **60** (15/15) | 1등주를 **60 거래일**(약 3개월) 단위로 본다 |
| `trim_fraction` | **1.0** (15/15) | 신호가 뜨면 **일부가 아니라 전량** 회피 |
| `trim_threshold` | -10 ~ -20% | 그 기간 이만큼 빠지면 발동 |
| `gold_weight` | **0.0** (13/15) | 회피자산은 **국채 100%**, 금은 쓰지 않음 |

나스닥·VIX 충격 규칙은 **보조**였습니다. 짧게 보고(5~10일), 얕은 기준(-4~-8%)에서,
짧게 피하는(10~20일) 쪽이 선택됐습니다.

금이 빠진 이유는 데이터에 있습니다. 금 펀드 자체의 최대 낙폭이 **-63%** 로,
주식이 무너질 때 같이 무너진 적이 많습니다. 국채 펀드는 -19% 입니다.

### 3. 성적표 (1980-01-02 ~ 2026-08-26, 1천만원 + 매월 50만원, 거래비용 포함)

| | 연평균 | 최대 낙폭 | 최종 평가액 | 회피 비중 | 매매 |
|---|---|---|---|---|---|
| **최적 규칙** | **16.64%** | **-42.8%** | **440.7억** | 17.3% | 연 5.8회 |
| 공격 (수익 우선) | 17.15% | -47.4% | 609.1억 | 16.9% | 연 4.7회 |
| 방어 (낙폭 우선) | 12.43% | -32.2% | 96.8억 | 33.7% | 연 4.1회 |
| 1등주 계속보유 | 13.90% | -67.4% | 256.0억 | 0% | 연 2.4회 |
| 나스닥 | 11.72% | -77.9% | 107.9억 | – | – |
| 국채 펀드 | 5.81% | -19.5% | 10.6억 | – | – |

최적 규칙은 학습구간에서 16.98%, **탐색이 보지 못한 검증구간(2006~)에서 16.16%** 로
거의 그대로 유지됐습니다.

### 4. 그런데 — 이 숫자를 그대로 믿으면 안 됩니다

전체 기간 숫자 하나가 많은 것을 숨깁니다. 10년 단위로 쪼개면 이야기가 달라집니다.

| 기간 | 그때의 1등주 | 최적 규칙 | 계속보유 | 수익 차이 | 낙폭 절감 |
|---|---|---|---|---|---|
| 1980–1989 | XOM → IBM | 15.12% | 11.35% | **+3.77%p** | 11.1%p |
| 1990–1999 | IBM → XOM → GE → MSFT | 22.48% | 20.10% | **+2.38%p** | 19.9%p |
| 2000–2009 | MSFT → GE → XOM | 10.07% | −1.25% | **+11.32%p** | 41.4%p |
| 2010–2019 | XOM → AAPL → MSFT | 18.59% | 19.54% | −0.95%p | 8.4%p |
| 2020–2026 | AAPL → MSFT → NVDA | 15.21% | 23.91% | **−8.70%p** | 12.1%p |

읽는 법:

- **수익 우위는 약세장에서만 나옵니다.** 2000년대(잃어버린 10년)에 +11.32%p 를
  벌어들인 것이 전체 성적의 대부분입니다. 2010년대와 2020년대 강세장에서는
  오히려 집니다. 최근 6년만 보면 8.7%p 뒤집니다.
- **낙폭 감소는 모든 10년 구간에서 나타납니다.** 이쪽이 훨씬 믿을 만한 효과입니다.
- 시작 연도를 1980~2024년으로 45번 바꿔가며 돌린 결과:

  | 기준 | 계속보유를 이긴 횟수 |
  |---|---|
  | 연평균 수익률(시간가중) | 22 / 45 |
  | 최종 평가액(적립 시점까지 반영) | 16 / 45 |
  | **최대 낙폭** | **45 / 45** (평균 18.6%p 개선) |

  두 수익 기준이 다른 이유는, 계좌가 가장 커졌을 때 어느 쪽이 잘했느냐에 따라
  시간가중과 금액가중이 갈리기 때문입니다.
  요컨대 **"언제 시작해도 더 번다"는 거짓이고, "언제 시작해도 덜 잃는다"는 참**입니다.

정직하게 요약하면: **이 규칙이 사는 것은 수익이 아니라 낙폭입니다.**
수익까지 이긴 것은 검증된 사실이지만, 그 이득이 특정 시대(약세장)에 몰려 있습니다.
그리고 결국 과거에 맞춰 고른 규칙이라 미래가 과거와 다르면 통하지 않습니다.

## 구조

```
app.py                 Flask 서버 + JSON API
src/config.py          티커, 기간, 파라미터 정의, 탐색 격자
src/leaders.py         시총 1위 타임라인 (+ 실시간 1위 확인)
src/datasource.py      온라인 수신 · 캐시 · 통합 패널
src/engine.py          백테스트 엔진 (목표비중 상태기계, 지표, 벤치마크)
src/optimize.py        워크포워드 파라미터 탐색 · 파레토 프론티어
src/advisor.py         "어제 종가 기준 오늘 할 일"
scripts/optimize_run.py  탐색 실행 스크립트
web/                   프론트엔드 (외부 요청 0개, 차트도 직접 그림)
data/seed/leaders.json 1위 교체 이력 (직접 수정 가능)
data/cache/            받아온 시세 CSV + manifest
data/results/          탐색 결과 JSON
```

### API

| 엔드포인트 | 설명 |
|---|---|
| `GET /api/status` | 어제 종가 지표 + 상태 + 목표 비중 + 매매 지시 (`stock`/`gold`/`bond` 로 현재 보유 전달) |
| `GET /api/backtest` | 지표 + 곡선 + 회피 구간 + 벤치마크 |
| `GET /api/point?start=` | 그 시점부터 시작했을 때의 성과 |
| `GET /api/timeline` | 연도별 시작 시점 전체 |
| `GET /api/optimize` | 저장된 탐색 결과 |
| `GET /api/meta` | 데이터 출처, 1위 이력, 기본 파라미터 |
| `POST /api/refresh` | 온라인에서 시세 재수신 |

모든 엔드포인트는 쿼리스트링으로 파라미터를 덮어쓸 수 있습니다.
예: `/api/backtest?crash_threshold=-12&shelter_days=40&gold_weight=0.5`
